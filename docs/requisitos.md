# Requisitos del Taller 6

| Requisito | Implementación |
|---|---|
| Monitoreo | Fecha automática, entrada manual o simulada, validación, origen y nivel |
| Descontaminación | HEPA, carbón, ventilación y combinación, duración de 1 a 120 min, avance y detención |
| Validación | Entrada y salida por sesión, reducciones y nivel final |
| Inteligencia de negocios | Cuatro KPI, barras antes/después, evolución, distribución y filtros |
| Persistencia | SQLite, sesiones vinculadas, muestras y alertas |
| Componente de inteligencia | Reglas documentadas y recomendaciones |
| Reporte | Estadísticas por tecnología y descarga de CSV |
| Informe y video | Informe técnico y guion de 5:40 para la demostración |

El sistema funciona sin hardware físico. Las salidas y las muestras intermedias son estimaciones simuladas.
