# Manual de usuario

1. En **Mediciones**, elige captura manual o un escenario simulado. Usa la misma semilla y escenario para reproducir concentraciones. La gráfica muestra hasta 40 entradas coincidentes con los filtros.
2. En **Tratamientos**, elige una entrada, tecnología y duración. Para ventilación puedes ajustar las concentraciones exteriores. Inicia, pausa, reanuda o detén el tratamiento. Cada minuto simulado dura 500 ms.
3. En **Validación**, elige una o dos sesiones finalizadas para revisar concentraciones antes y después, cambio porcentual y valores residuales. Un porcentaje negativo significa que la concentración aumentó.
4. En **Panel BI**, aplica filtros por fecha, tecnología, sesión, escenario, nivel y origen. El contaminante elegido fija la unidad del gráfico.
5. En **Alertas y reportes**, filtra por nivel y contaminante. Selecciona periodo o sesión y descarga un PDF o CSV.
6. En **Datos y ajustes**, guarda un respaldo antes de restaurar otro. La aplicación comprueba esquema, integridad y relaciones. Recrear la demostración reemplaza los registros identificados como demo desde este módulo.
7. Usa **Modo oscuro** o **Modo claro** para cambiar la apariencia. Desde **Datos y ajustes** puedes elegir la duración predeterminada. Las preferencias se conservan al cerrar.

Los valores de salida describen el modelo simulado. Usa los avisos como criterios de análisis académico.
