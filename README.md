# Air Quality Intelligence

Universidad Manuela Beltrán · Inteligencia de Negocios · Taller 6

Integrantes: Valery Michell Herrera y Daniel Felipe Rojas.

Aplicación web de monitoreo y simulación de purificación del aire.

Requiere Node.js 24 y npm. Ejecuta `npm ci` y `npm run dev`. Abre http://127.0.0.1:3000.
Para ejecutar la compilación, usa `npm run build` y `npm start`.
Copia `.env.example` a `.env` para personalizar el puerto y la ubicación de SQLite.
